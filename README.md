# SmartOps 🚀

### AI-Powered Employee Task & Workflow Management System

SmartOps is a full-stack employee task and workflow management system built with **React, FastAPI, PostgreSQL, and Gemini AI**.

It provides authentication, role-based access, employee task management, workflow management, dashboards, and AI-powered task analysis through a modern web interface.

## 🌐 Live Demo

👉 https://smart-ops-nine.vercel.app/

## 💻 GitHub Repository

👉 https://github.com/salman55667ff-ui/SmartOps

## ✨ Features

- 🔐 JWT-based authentication
- 👥 Role-based access control
- 👨‍💼 Employee management
- 📋 Task creation and management
- 🔄 Workflow management
- 📊 Dashboard and task statistics
- 🤖 AI-powered task analysis using Gemini AI
- 🗄️ PostgreSQL database integration
- 🔗 React frontend connected with FastAPI backend
- 🌐 Deployed and publicly accessible
